# 🌌 Deep Work & Focus Analytics

A high-performance, futuristic productivity web application designed to help you achieve deep work states. Built with a zero-dependency architecture (Vanilla JS/CSS) and a Python FastAPI backend.

## ✨ Features

*   **Liquid Particle Focus Sphere**: A 3D interactive, canvas-based timer that responds to your focus intensity and mouse movements.
*   **Anti-Distraction AI Guardian**: A procedural SVG Bonsai Tree that grows as you focus but triggers a "Glitch Engine" penalty if you switch tabs (Page Visibility API).
*   **Binaural Audio Matrix**: A 4-node synthesizer using the Web Audio API for generating ambient soundscapes (Rain, Space, White Noise, Binaural Beats).
*   **3D Isometric Analytics Grid**: Smooth, CSS-based 3D visualizations of your focus sessions and statistics.
*   **Holographic Session Logger**: A cyberpunk-style task manager with native drag-and-drop, scanline glows, and category tagging.
*   **Achievements System**: Gamified badges and streaks to keep you motivated.

## 🛠️ Technology Stack

*   **Frontend**: Native HTML5, Vanilla JavaScript (ES6+ Modules), CSS3 (CSS Variables, 3D Transforms) - *Zero external JS/CSS dependencies!*
*   **Backend**: Python 3, FastAPI, Uvicorn
*   **Database**: SQLite (Native)
